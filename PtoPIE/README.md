# PtoPIE

스마트폰(Galaxy S10+)을 "40핀 없는 라즈베리파이"처럼 쓰고, USB로 Raspberry Pi Pico에 제어 신호를 보내는 구상의 결과물 모음입니다.

| 파일 | 내용 |
|---|---|
| [REPORT.md](REPORT.md) | 가능성 분석: 폰 CPU 연산 능력, USB로 피코 제어, 충전 동시 연결, 추가 문제점과 단계별 진행안 |

## 요약

- 폰 CPU 연산과 USB로 피코 제어는 둘 다 루팅 없이 가능합니다. 단, Android는 실시간 OS가 아니므로 타이밍이 중요한 루프는 피코가 맡아야 합니다.
- 가장 불확실한 부분은 2포트 분배기로 충전과 피코 연결을 동시에 하는 것입니다. 단순 Y자 케이블이 아니라 PD 충전 입력이 있는 USB-C 허브가 필요하고, S10+에서 되는지는 실물 확인이 필요합니다. 안 되면 Pico W의 BLE/Wi-Fi가 대안입니다.
- 원래 Pico는 Micro-USB B 단자라서 C to C 케이블은 바로 맞지 않습니다.
